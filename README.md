# 🚀 CV Alto Impacto v2.0 (Bilingual Strategic Resume Builder)

> Generador web de currículums de alto impacto con arquitectura a doble columna, diseñado para que estudiantes y profesionistas de cualquier sector creen CVs de clase mundial en **Español e Inglés** con exportación directa a PDF y formato optimizado para filtros ATS.

Inspirado en la **Metodología de Creación de CV de Platzi** y los estándares de reclutamiento técnico internacional (la regla de los 6 segundos de escaneo, formulación de logros cuantificables y jerarquía visual estratégica).

## 🎯 ¿Para quién es esta herramienta? (9 Arquetipos de Carrera)

La aplicación incluye **9 plantillas y arquetipos pedagógicos** adaptados para todo tipo de carreras e industrias:

1. 🎓 **Estudiante / Primer Empleo / Prácticas**:
   - Para estudiantes o recién egresados sin amplia experiencia laboral formal.
   - Enfatiza proyectos de titulación, hackatones, promedio sobresaliente y aprendizaje autónomo.
2. 💻 **Desarrollador de Software / Tech & AI**:
   - Para programadores (Frontend, Backend, Full Stack, Cloud o Datos).
   - Enfatiza stack tecnológico, proyectos en producción, optimización de latencia y CI/CD.
3. 🔄 **Cambio de Carrera / Perfil Híbrido**:
   - Para profesionistas en transición hacia la tecnología.
   - Conecta el bagaje previo con las nuevas habilidades mediante narrativa en "Sobre Mí" y habilidades transferibles.
4. 📊 **Administración & Ventas B2B**:
   - Para coordinadores comerciales, ejecutivos de cuentas, operaciones y finanzas.
   - Enfatiza cuotas de ventas, gestión de CRM, facturación y retención de clientes.
5. 👨‍🍳 **Oficios & Servicios Industriales**:
   - Para técnicos electromecánicos, mantenimiento industrial, almacén y logística.
   - Enfatiza certificaciones DC-3, seguridad LOTO, disponibilidad de maquinaria y cero accidentes.
6. 🎨 **Creativos, Diseño UX/UI & Marketing**:
   - Para diseñadores de producto, branding, contenido y marketing digital.
   - Enfatiza Figma, design systems, prototipado interactivo y métricas de conversión.
7. 🏥 **Salud & Bienestar**:
   - Para médicos generales, enfermería, salud ocupacional y psicología.
   - Enfatiza protocolos clínicos, normas oficiales de salud (NOM-030/035) y medicina preventiva.
8. 📚 **Educación & Docencia**:
   - Para profesores universitarios, diseñadores curriculares y capacitadores.
   - Enfatiza pedagogía activa, plataformas EdTech/LMS y retención estudiantil.
9. 📝 **Plantilla en Blanco**:
   - Para iniciar desde cero con guías contextuales en cada campo.

## ✨ Nuevas Características v2.0

- 📊 **Score de Completitud Gamificado + "Next Best Action"**:
  - Medidor circular SVG en tiempo real que evalúa la salud de tu CV (0 a 100%).
  - Muestra una **única acción recomendada prioritaria** para maximizar tus probabilidades de entrevista.
  - Efecto de confetti y niveles: *Borrador ➔ En Construcción ➔ Competitivo ➔ Alto Impacto 🌟*.
- 🎨 **8 Esquemas de Color Profesionales**:
  - *Corporativo Azul, Grafito Elegante, Verde Ejecutivo, Borgoña Clásico, Índigo Moderno, Terracota Cálido, Bosque Natural y Minimalista B&W*.
- 🔤 **4 Familias Tipográficas**:
  - *Inter* (Moderna), *Merriweather* (Serif clásica), *Source Sans 3* (Limpia), *Playfair Display* (Elegante).
- 📚 **Biblioteca de Viñetas Pre-escritas**:
  - Banco de fórmulas con acción y métricas por industria listas para insertar con un clic.
- 🔍 **Analizador de Coincidencia ATS**:
  - Pega la descripción de una vacante y el algoritmo client-side te indica el % de coincidencia y qué palabras clave prioritarias te faltan.
- 📱 **Código QR Integrado**:
  - Genera automáticamente un código QR en la barra lateral del CV impreso para que los reclutadores escaneen tu LinkedIn o portafolio.
- 💾 **Auto-guardado en LocalStorage**:
  - Guarda cada cambio al instante en tu navegador. Tus borradores no se pierden al recargar.
- 🛡️ **Privacidad Absoluta (Privacy-First)**:
  - Todo el procesamiento ocurre en tu navegador. Zero almacenamiento en servidores de terceros.
- 📱 **Diseño Responsivo con Vista Previa Móvil**:
  - Botón flotante para alternar entre edición y previsualización en celulares y tablets.
- 🖨️ **Exportación Directa a PDF**:
  - Calibrado para hoja Carta (US Letter) sin desbordes.

## 💻 Ejecución Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/MetaNetMx/cv-alto-impacto.git
   cd cv-alto-impacto
   ```
2. Inicia el servidor con Node.js (v18 o superior):
   ```bash
   node server.js
   ```
3. Abre tu navegador en:
   ```
   http://localhost:3000
   ```
